# Telegram Helper AI Bot

دستیار هوشمند تلگرام با نام «هلپر» (Helper) مجهز به موتور استدلال، جستجوی زنده وب، قابلیت استفاده در گروه‌ها و چت خصوصی، و فیلترهای ضد توهین و محتوای نامناسب.

## ویژگی‌ها

- **عدم استفاده از ایموجی:** در کلیه بخش‌ها، پاسخ‌ها و پیام‌های ربات هیچ‌گونه ایموجی استفاده نمی‌شود.
- **پاسخگویی در گروه‌ها:** 
  - با صدا زدن «هلپر» یا «helper»
  - با منشن کردن آیدی ربات
  - با ریپلای روی پیام دیگران به همراه صدا زدن ربات (ربات پیام مبدأ را خوانده و با در نظر گرفتن آن پاسخ می‌دهد)
- **موتور استدلال سریع (Reasoning):**
  - تشخیص دقیق نیاز کاربر
  - درک کانتکست پیام‌های ریپلای‌شده
  - بررسی خودکار نیاز به جستجوی وب
  - ارائه پاسخ‌های منطقی و مستقیم
- **جستجوی زنده وب:** استخراج اطلاعات روز و مستندات با استناد به منابع.
- **گاردریل امنیتی سرسخت:** رد قاطع و بدون استثنای هرگونه درخواست توهین‌آمیز، فحاشی یا محتوای غیرصریح.

## پیش‌نیاز مهم در تلگرام (Group Privacy)

برای اینکه ربات بتواند در گروه‌ها پیام‌هایی که در آن‌ها صدا زده می‌شود یا روی آن‌ها ریپلای می‌شود را دریافت کند:
1. در تلگرام به @BotFather بروید.
2. دستور `/mybots` را بزنید و ربات خود را انتخاب کنید.
3. به مسیر `Bot Settings` -> `Group Privacy` بروید.
4. آن را روی **Turn off** بگذارید (تا وضعیت آن `Privacy mode is disabled` شود).

## نصب و راه‌اندازی سریع در سرور لینوکس (تک‌دستور)

کافیست وارد سرور لینوکس خود شوید و دستور زیر را اجرا کنید:

```bash
curl -sSL https://raw.githubusercontent.com/Aporis3674/telegram-helper-bot/main/install.sh | sudo bash
```

این اسکریپت به صورت تعاملی اطلاعات زیر را از شما می‌گیرد:
- توکن ربات تلگرام (از BotFather)
- کلید API هوش مصنوعی (OpenAI / OpenRouter / Groq)
- آدرس Base URL (در صورت استفاده از ارائه‌دهنده‌های دیگر)
- نام مدل مورد نظر

## مدیریت سرویس ربات در لینوکس

- مشاهده وضعیت:
  ```bash
  systemctl status helper-bot
  ```
- مشاهده زنده لاگ‌ها:
  ```bash
  journalctl -u helper-bot -f
  ```
- راه‌اندازی مجدد:
  ```bash
  systemctl restart helper-bot
  ```
- متوقف ساختن ربات:
  ```bash
  systemctl stop helper-bot
  ```
